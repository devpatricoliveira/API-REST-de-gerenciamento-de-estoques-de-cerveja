## 📌 Sobre o Projeto

Nesta live coding, aprendemos a testar unitariamente uma API REST para o gerenciamento de estoques de cerveja. O projeto demonstra, na prática, como criar testes unitários com os frameworks **JUnit**, **Mockito** e **Hamcrest**, além de aplicar **TDD (Test-Driven Development)** no desenvolvimento das funcionalidades da API.

O foco foi construir uma base sólida de testes unitários para operações essenciais como criação, listagem, busca por nome e exclusão de cervejas, além das funcionalidades de incremento e decremento de estoque.

---

## 🧪 Tópicos Abordados

Durante a sessão, foram explorados os seguintes assuntos:

- ✅ Clone de um projeto via Git para iniciar o desenvolvimento de testes unitários.
- 🧠 Conceitos fundamentais sobre testes:
  - A pirâmide de testes.
  - A importância dos testes no ciclo de desenvolvimento.
- 🔍 Foco nos **testes unitários** e sua relevância prática.
- 🛠 Principais frameworks Java utilizados:
  - JUnit 5
  - Mockito
  - Hamcrest
- 🧰 Desenvolvimento de testes unitários para:
  - Criação de cervejas.
  - Listagem de cervejas.
  - Consulta de cerveja por nome.
  - Exclusão de cervejas.
- 💡 TDD aplicado às funcionalidades de:
  - Incremento de estoque.
  - Decremento de estoque.
